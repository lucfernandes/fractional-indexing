# Fractional Indexing PHP

A functional port of the [rocicorp/fractional-indexing](https://github.com/rocicorp/fractional-indexing) algorithm for PHP >= 7.1.

Fractional indexing is a technique to generate order keys that allow for inserting items at any position in a list without needing to reorder the adjacent items.

## Compatibility

- PHP >= 7.1
- Zero runtime dependencies
- Agnostic to databases or frameworks

## Installation

```bash
composer require fractional-indexing/fractional-indexing-php
```

## Quick Start

```php
use FractionalIndexing\FractionalIndexing;

// Generate the initial key
$firstKey = FractionalIndexing::generateKeyBetween(null, null); // "a0"

// Insert after the first key
$secondKey = FractionalIndexing::generateKeyBetween($firstKey, null); // "a1"

// Insert before the first key
$zerothKey = FractionalIndexing::generateKeyBetween(null, $firstKey); // "Zz"

// Insert between two keys
$midKey = FractionalIndexing::generateKeyBetween($firstKey, $secondKey); // "a0V"
```

## Generating Multiple Keys

If you need to insert multiple items at once between two elements, you can use `generateNKeysBetween`:

```php
$keys = FractionalIndexing::generateNKeysBetween('a0', 'a1', 3);
// ['a0G', 'a0V', 'a0l']
```

## Database Usage & Lexicographical Ordering

The keys generated by this library are designed to be sorted **lexicographically**. 
When storing these keys in a database (like MySQL, PostgreSQL, or SQLite), ensure that the column uses a **case-sensitive** collation (e.g., `utf8mb4_bin` in MySQL).

Example MySQL schema:
```sql
CREATE TABLE items (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    order_key VARCHAR(255) COLLATE utf8mb4_bin NOT NULL,
    INDEX (order_key)
);
```

> **Note:** This library does not enforce a length limit on the generated keys. It is the responsibility of the consumer application to handle potential database column length limits if the keys grow significantly after thousands of midpoint insertions.
